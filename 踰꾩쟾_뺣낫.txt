새김 행사 지도 편집기
버전: 1.0.0
제작일: 2026-08-02

기존 프로젝트 소스를 사용하지 않고 처음부터 새로 제작한 정적 웹 프로젝트입니다.

검증 완료 항목
- JavaScript 문법 검사
- API 키 미입력 초기 화면
- 지도 편집기 초기화
- 샘플 요소 7개 렌더링
- 부스 추가
- 시설물 이름 수정
- 시설물 복제
- 통로 점 추가 및 완성
- 샘플 JSON 문법 검사

실제 Google Maps 지도 타일, Places 검색 및 위치 권한은 사용자의 Google Maps API 키와 Google Cloud 설정이 필요합니다.
