# 새김 행사 지도 편집기

Google Maps 위에 행사 부스, 무대, 텐트, 편의시설, 통로와 행사 구역을 직접 배치하는 관리자용 지도 편집기입니다.

## 실행 방법

### Windows

1. 압축을 풉니다.
2. `run.bat`를 더블클릭합니다.
3. 브라우저에서 `http://localhost:8080`이 열립니다.
4. 처음 화면에서 Google Maps API 키를 입력합니다.

Python이 설치되어 있지 않다면 VS Code의 Live Server 또는 다른 정적 웹서버로 `index.html`을 실행해도 됩니다.

### 직접 실행

프로젝트 폴더에서 다음 명령을 실행합니다.

```bash
python -m http.server 8080
```

그 다음 브라우저에서 아래 주소를 엽니다.

```text
http://localhost:8080
```

## Google Maps 설정

Google Cloud Console에서 다음 API를 활성화하세요.

- Maps JavaScript API
- Places API (New)

권장 설정:

- 결제 계정 연결
- API 키의 애플리케이션 제한을 `웹사이트`로 설정
- 로컬 테스트 허용 주소: `http://localhost:8080/*`
- 실제 배포 주소도 허용 목록에 추가
- API 제한에서 Maps JavaScript API와 Places API만 허용

API 키는 편집기 화면에서 입력하며 브라우저의 `localStorage`에만 저장됩니다. 프로젝트 JSON에는 API 키가 포함되지 않습니다.

## 포함된 기능

- Google Maps 장소·주소 검색
- 부스, 무대, 텐트, 푸드 부스 배치
- 화장실, 안내소, 출입구 포인트 배치
- 통로 선 그리기
- 행사 구역 다각형 그리기
- 안내 텍스트 배치
- 시설물 이동 및 크기 조절
- 이름, 번호, 설명, 색상, 투명도 수정
- 레이어 선택, 검색, 순서 변경
- 잠금, 숨김, 복제, 삭제
- 1m·2m·5m·10m 격자와 스냅
- 실행 취소 및 다시 실행
- 브라우저 자동 저장
- JSON 내보내기 및 불러오기
- 사용자용 읽기 전용 지도 미리보기
- 시설물 클릭 후 Google Maps 도보 길찾기

## 기본 조작

- 부스나 시설물 추가: 왼쪽 도구 선택 → 지도 클릭
- 통로·구역: 도구 선택 → 지도에서 점 추가 → 하단 `완료`
- 편집: 지도 시설물 또는 레이어 목록 클릭
- 크기 조절: 선택된 사각 시설물의 모서리 핸들 드래그
- 통로·구역 수정: 선택 후 꼭짓점 드래그

## 단축키

| 단축키 | 기능 |
|---|---|
| `Ctrl + S` | 저장 |
| `Ctrl + Z` | 실행 취소 |
| `Ctrl + Shift + Z` 또는 `Ctrl + Y` | 다시 실행 |
| `Ctrl + D` | 선택 항목 복제 |
| `Delete` | 선택 항목 삭제 |
| `Enter` | 통로·구역 그리기 완료 |
| `Esc` | 그리기 취소 또는 선택 해제 |

## 저장 구조

현재 버전은 서버 없이 브라우저에 자동 저장합니다.

- 자동 저장: `localStorage`
- 수동 백업: JSON 파일
- 다른 컴퓨터로 이동: JSON 내보내기 → 새 컴퓨터에서 JSON 불러오기

다음 개발 단계에서 Firebase를 연결하면 행사별 공개 주소와 여러 관리자 계정을 추가할 수 있습니다.

## 주의 사항

- 브라우저 위치 기능은 `localhost` 또는 HTTPS 환경에서 사용하는 것이 안전합니다.
- Google Maps 길찾기는 선택한 시설물의 중심 좌표로 연결됩니다.
- 임시 행사장 내부 통로의 실제 안내선 계산은 아직 자체 길찾기 엔진이 아니라 편집자가 그린 안내 통로를 시각적으로 보여주는 단계입니다.
- 행사장 내부 A* 길찾기와 Firebase 배포는 다음 단계에서 추가할 수 있습니다.
